# 💰 App Orçamento Pessoal

Aplicação web desenvolvida para praticar programação e criação de uma ferramenta de controle de orçamento pessoal.

## 📌 Sobre o projeto

## 🖥️ Preview

![Preview do projeto]()

O projeto tem como objetivo permitir a organização de informações relacionadas ao orçamento pessoal através de uma aplicação web.

Foi desenvolvido como projeto prático para aplicar conhecimentos de HTML, CSS e JavaScript.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 Conhecimentos praticados

* Estruturação de páginas web
* Estilização com CSS
* JavaScript
* Lógica de programação
* Manipulação de dados
* Interação com o usuário
* Organização de uma aplicação web

Aplicar conhecimentos de desenvolvimento web na criação de uma aplicação com uma finalidade prática.
