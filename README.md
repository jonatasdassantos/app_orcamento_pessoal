# 💰 App Orçamento Pessoal

Aplicação web para **cadastro, consulta, filtragem e exclusão de despesas**, desenvolvida com HTML5, CSS3, JavaScript e Bootstrap.

O projeto foi desenvolvido como exercício prático para aplicar conceitos de **programação orientada a objetos, armazenamento de dados no navegador e manipulação do DOM**.

## 🖥️ Preview

![Preview do projeto](preview.png)

## 🎯 Principais funcionalidades

* Cadastro de despesas
* Registro de:

  * Data
  * Tipo
  * Descrição
  * Valor
* Classificação das despesas por categoria:

  * Alimentação
  * Educação
  * Lazer
  * Saúde
  * Transporte
* Validação dos campos obrigatórios
* Armazenamento das despesas no `localStorage`
* Consulta dos registros cadastrados
* Filtros por:

  * Ano
  * Mês
  * Dia
  * Tipo
  * Descrição
  * Valor
* Exclusão de despesas
* Atualização dinâmica da lista de registros
* Mensagens de sucesso e erro através de modal

## 🧠 Conceitos praticados

Durante o desenvolvimento do projeto foram praticados conceitos importantes de JavaScript, como:

* Programação Orientada a Objetos
* Criação de classes e métodos
* Construtores
* Validação de dados
* Manipulação do DOM

* Criação dinâmica de elementos HTML

* Armazenamento de dados com `localStorage`

* Geração e controle de identificadores

## 💾 Armazenamento de dados

O projeto utiliza o **Local Storage do navegador** para armazenar as despesas cadastradas.

Os registros são convertidos para JSON antes de serem armazenados e posteriormente recuperados e convertidos novamente em objetos JavaScript.

## 📌 Sobre o projeto

O App Orçamento Pessoal foi desenvolvido para praticar conceitos de desenvolvimento web e programação JavaScript através da criação de uma aplicação capaz de armazenar e gerenciar registros de despesas.

Um dos principais objetivos do projeto foi aplicar **Programação Orientada a Objetos**, utilizando classes para organizar a estrutura das despesas e o gerenciamento dos dados.

A aplicação também utiliza o `localStorage`, permitindo que os registros permaneçam armazenados no navegador mesmo após o fechamento da página.

## 🎯 Objetivo

Consolidar conhecimentos de **HTML5, CSS3 e JavaScript**, colocando em prática conceitos de programação orientada a objetos, armazenamento de dados, filtragem de informações e manipulação dinâmica da interface.
